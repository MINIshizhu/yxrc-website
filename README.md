# YXRC 安防工程公司官网

一个现代化的安防工程公司企业官网，采用科技感设计风格，支持响应式布局。

## 项目概述

YXRC 安防工程公司官网是一个专业的企业展示网站，旨在展示公司业务、产品服务、工程案例，并提供在线咨询功能。

### 核心目标
- 获客引流
- 公司形象展示
- 项目案例展示
- 在线咨询转化

### 目标客户
- 企业客户
- 园区管理方
- 学校/教育机构
- 政府单位
- 物业公司

## 技术栈

- **HTML5** - 语义化标签
- **CSS3** - Flexbox/Grid布局、CSS变量、动画效果
- **JavaScript (ES6+)** - 原生JS，无框架依赖
- **响应式设计** - 支持PC、平板、手机等多设备

## 快速开始

### 1. 查看网站

直接在浏览器中打开 `index.html` 文件即可查看网站。

### 2. 本地开发

如果需要在本地开发服务器中运行：

```bash
# 使用 Python
python -m http.server 8000

# 或使用 Node.js 的 http-server
npx http-server

# 或使用 VS Code 的 Live Server 插件
```

然后在浏览器中访问 `http://localhost:8000`

### 3. 部署上线

将整个项目文件夹上传到您的Web服务器即可。

## 自定义配置

### 修改配色方案

在 `css/style.css` 文件顶部的 `:root` 部分修改CSS变量：

```css
:root {
  --primary-color: #0066ff;      /* 主色调 */
  --secondary-color: #00d4ff;    /* 辅助色 */
  --accent-color: #00ff88;        /* 强调色 */
  --bg-dark: #0a0e27;            /* 背景色 */
  /* ... 更多变量 */
}
```

### 修改公司信息

在各HTML文件中查找并修改以下内容：
- 公司名称
- 联系电话
- 邮箱地址
- 公司地址
- 其他文本内容

### 添加真实图片

1. 将产品图片放到 `images/products/` 目录
2. 将案例图片放到 `images/cases/` 目录
3. 将方案图片放到 `images/solutions/` 目录
4. 在HTML中更新 `img` 标签的 `src` 属性

## 后端集成建议

### 方案一：静态网站 + 第三方服务

- 使用 **腾讯云COS/阿里云OSS** 托管静态文件
- 使用 **腾讯云开发/阿里云函数计算** 处理表单提交
- 集成 **百度统计/Google Analytics** 进行数据分析
- 使用 **美洽/环信** 等第三方在线客服系统

### 方案二：集成CMS系统

推荐以下CMS系统：

1. **Strapi** (Node.js)
2. **WordPress** (PHP)
3. **Ghost** (Node.js)
4. **Dedecms** (PHP，国内常用)
5. **PageAdmin** (ASP.NET，国内常用)

### 方案三：全栈开发

使用以下技术栈进行全栈开发：

- **前端**: React/Vue + Next.js/Nuxt.js
- **后端**: Node.js/Python/Go
- **数据库**: MongoDB/MySQL
- **部署**: Docker + Nginx
