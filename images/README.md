# 图片资源说明

## 图片目录结构

```
images/
├── placeholder.jpg          # 占位图片（需要添加）
├── products/                # 产品图片目录
│   ├── camera-1.jpg
│   ├── nvr-1.jpg
│   └── ...
├── cases/                   # 案例图片目录
│   ├── case1.jpg
│   ├── case2.jpg
│   └── ...
└── solutions/               # 方案图片目录
    ├── park-security.jpg
    ├── school-security.jpg
    └── ...
```

## 如何添加图片

### 1. 创建占位图片

在 `images/` 目录下创建一个名为 `placeholder.jpg` 的占位图片。
推荐尺寸：800x600 像素

可以使用在线工具生成占位图片：
- https://placeholder.com/
- https://via.placeholder.com/800x600/0a0e27/0066ff?text=Image+Placeholder

### 2. 添加产品图片

将产品图片放到 `images/products/` 目录

推荐尺寸：
- 宽度：800px
- 高度：600px
- 格式：JPG 或 WebP
- 大小：< 200KB

### 3. 添加案例图片

将案例图片放到 `images/cases/` 目录

推荐尺寸：
- 宽度：800px
- 高度：600px
- 格式：JPG 或 WebP
- 大小：< 200KB

### 4. 添加方案图片

将方案图片放到 `images/solutions/` 目录

推荐尺寸：
- 宽度：800px
- 高度：600px
- 格式：JPG 或 WebP
- 大小：< 200KB

## 图片优化建议

1. **压缩图片**
   - 使用 TinyPNG (https://tinypng.com/) 压缩图片
   - 保持图片质量在 80% 左右

2. **使用 WebP 格式**
   - WebP 格式比 JPG 小 25-35%
   - 使用在线转换工具：https://squoosh.app/

3. **图片命名规范**
   - 使用小写字母和连字符
   - 描述性命名，如：`hd-network-camera.jpg`
   - 避免使用中文字符和空格

4. **CDN 加速**
   - 建议使用 CDN 加速图片加载
   - 如：阿里云 OSS、腾讯云 COS、七牛云等
